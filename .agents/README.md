# `.agents/` — 共有エージェント設定（正本）

このディレクトリに、**ツールをまたいで共通の**ワークフロー・ルール・スキルを置きます。

| 種別 | パス | 役割 |
|------|------|------|
| ルール（詳細の正本） | `rules/` | 開発ライフサイクル、Git、GitHub、Android、自動実行の境界 |
| ワークフロー文言 | `workflows/` | `/save`、`/resume`、`/cleanup` 等の手順テンプレ |
| 検証スキル | `skills/` | 実装後のビルド・Lint・テスト検証など |

## エディタ / AI とこのリポジトリの対応

| 利用ツール | リポジトリ側の入口 |
|------------|-------------------|
| **Cursor** | ルートの **`AGENTS.md`**、**`.cursor/rules/`** |
| **Antigravity** | **`.antigravityrule`**（上記 `rules/` を YAML で列挙） |

詳細ルールの編集は **`rules/*.md`** を一度の更新先にし、Cursor / Antigravity 双方から同じ内容を参照できる状態を保つ。
