# 警告抑制リスト (Suppression List)

このドキュメントでは、技術的な理由により一時的に、または意図的に無視（Suppress）している警告と、その解除条件を記録します。

## 運用ルール
- 警告を無視する場合は、必ずこのリストに理由と解除条件を追記してください。
- `verify-android-implementation` スキルの実行時、Step 0 でこのリストを確認し、解除条件を満たしている項目があれば優先的に対応してください。
